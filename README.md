# Vietnam & Cambodia 2027

A static travel-itinerary site (plain HTML/CSS/JS, no build step).

- `index.html` – page shell and navigation
- `js/data.js` – **all trip content** (hotels, flights, days, things to do, phrases) – edit here
- `js/app.js` – rendering, map and read-aloud logic
- `css/style.css` – styling
- `vendor/leaflet/` – bundled Leaflet 1.9.4 (BSD-2) for the map

Publish with GitHub Pages: Settings → Pages → deploy from branch → `/ (root)`.
